# Stock Price Data Analysis

## 📌 Project Overview

This project performs exploratory data analysis (EDA) on global stock market datasets using Python and Jupyter Notebook. The main objective is to analyze stock market trends, identify volatility patterns, and understand relationships between different companies and sectors.
The project uses data cleaning, visualization, and analysis techniques to generate meaningful insights from stock price data.

## 🎯 Objectives

- Perform stock market data analysis
- Understand stock price trends and volatility
- Analyze relationships between companies and sectors
- Practice data cleaning and preprocessing
- Create visualizations for better understanding of the dataset

## 📊 Dataset Information

The project uses the `World_Stock_Prices_Dataset` dataset containing stock price records of multiple global companies.

### Key Features in Dataset
- Date
- Open Price
- High Price
- Low Price
- Close Price
- Volume
- Brand Name
- Industry Tag
- Country
